# KeyBridge / 键桥 v0.2.0-beta.2

## 中文

### 本轮更新

- 修复雷雳网桥已有地址、但应用无法取得接口而无法发现对方的问题；有线发现与输入继续限定在雷雳网桥。
- 有线 TCP 启用小包即时发送；菜单打开时心跳继续运行，减少输入等待与误判断连。
- 两台 Mac 同步「设备 → 应用于」的输入去向，任意一台选择即可。
- 原生多指路径补全 Quartz 29 / 30 两类事件，保留原始手势交由目标 macOS 和应用判断，未把手势写死成快捷键。
- 调整来源内置触摸板隔离：远端转发时抑制已识别内置触摸板对本机指针的影响，外置及无法识别的鼠标保留本机使用。
- 移除影响全部鼠标的全局指针处理，修复有线转发时实体鼠标漂移的回归。
- 整理应用图标资源关联及安装刷新流程。启动台图标是否刷新仍取决于实际安装后的系统显示，不能据打包完成推定缓存已更新。

### 实测范围

2026-10-29，用户在 **M1 Pro MacBook → Mac mini M4，两台 macOS 15.8.1** 的有线直连环境中确认：输入、多指手势、来源触摸板隔离及外置鼠标表现正常。本次结果不代表所有 Mac、macOS 版本、应用和每一种手势都已验证。此前蓝牙实测覆盖打字、指针、点击、拖动和双指滚动。

### 连接建议：请先读

- **蓝牙延迟较高，触摸板尤其明显，建议仅临时使用或备用；日常使用优先有线。**
- 购买明确标注认证的 **雷雳 3 / Thunderbolt 3 或雷雳 4 / Thunderbolt 4 双 USB-C 线**。USB4 线需由厂商明确说明兼容雷雳。
- “全功能 Type-C”“100 W / 240 W”“支持视频”“10 Gb/s”不能单独保证 Mac 间雷雳网桥可用。
- **Mac mini（2024，M4 / M4 Pro）接背面接口**：M4 背面为雷雳 4，M4 Pro 背面为雷雳 5。前面两个 USB-C 仅为最高 10 Gb/s 的 USB 3，不提供本模式所需的雷雳连接。
- 「原生多指手势 · 实验功能」仍为来源端单独选项、默认关闭；启用后重新选择目标继续转发。该路径依赖未公开的 macOS 行为。

### 安装限制

这是 Apple Silicon 测试版，本地签名，**不是 Apple Developer ID 签名，也未经 Apple 公证**。两台都应使用同一版本并将应用放入「应用程序」。首次打开和替换安装可能需要确认应用专属安全提示及隐私权限，详见[安装说明](https://github.com/winglight9/KeyBridge/blob/main/docs/setup.md)。

## English

### Changes

- Resolve Thunderbolt Bridge interface discovery when the bridge has an address but is absent from the default network path. Wired discovery and input remain restricted to the bridge.
- Disable TCP delay for small input packets and keep heartbeats running while a menu is open, reducing packet waiting and false disconnects.
- Synchronize **Device → Apply to** between both Macs; choose the route on either Mac.
- Carry both Quartz native gesture event types 29 and 30. The target macOS/app interprets the original gesture; gestures are not replaced with fixed keyboard shortcuts.
- Isolate the recognized source built-in trackpad during forwarding, while external and unidentified pointer sources stay local.
- Remove global cursor handling that affected every mouse, fixing the external-mouse drift regression during wired forwarding.
- Update app icon resource association and installation refresh handling. Packaging alone does not establish that Launchpad has refreshed its displayed icon.

### Physical acceptance scope

On **2026-10-29**, the user confirmed wired input, multi-finger gestures, source trackpad isolation and external-mouse behavior on an **M1 Pro MacBook → M4 Mac mini, both running macOS 15.8.1**. This result is specific to that setup, not a guarantee for every Mac, OS, app or individual gesture. Earlier Bluetooth checks covered typing, pointer movement, clicks, dragging and two-finger scrolling.

### Connection advice

- **Bluetooth has noticeable latency, especially with the trackpad. Use it temporarily or as a backup; prefer wired for daily work.**
- Choose a **certified Thunderbolt 3 or Thunderbolt 4 cable with USB-C connectors**. Consider USB4 only when the manufacturer explicitly confirms Thunderbolt compatibility.
- “Full-featured USB-C,” “100 W/240 W,” video support or “10 Gb/s” alone does not establish Mac-to-Mac Thunderbolt networking support.
- **Use a rear port on Mac mini (2024, M4/M4 Pro)**: Thunderbolt 4 on M4, Thunderbolt 5 on M4 Pro. Its front USB-C ports provide USB 3 up to 10 Gb/s, not the Thunderbolt connection required here.
- The source-side **Native multi-finger gestures · Experimental** option remains off by default. Enable it and reselect the destination to resume. It depends on undocumented macOS behavior.

### Distribution limitations

This is an Apple Silicon beta, locally signed, **without Apple Developer ID signing or Apple notarization**. Install the same version in Applications on both Macs. Initial launch and replacement may require app-specific macOS security and privacy approval; see the [setup guide](https://github.com/winglight9/KeyBridge/blob/main/docs/setup.md).
